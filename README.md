# AgroVision

AI-powered disease diagnosis tool for potatoes, built to help Kenyan smallholder farmers diagnose potato disease from photos and connect with buyers.

## Team Project
Built collaboratively as a final year project by:
- Farid (AwdhatCodes)
- Daniel Mwariri (Mwariri254)
- Meshack Mutunga (meshmell100)

## Tech Stack
- **Frontend:** React
- **Backend:** Node.js/Express, Python (AI engine)
- **Database:** PostgreSQL
- **AI:** CNN model (MobileNetV2) for potato disease classification, with OpenCV for image processing
- **Deployment:** Vercel

## Features
- Photo-based potato disease diagnosis using a trained CNN model
- Marketplace connecting farmers to buyers
- Interactive mapping (Leaflet)
- Payment integration (M-Pesa, PayPal, Stripe)

Live at: agrovision-rouge.vercel.app
